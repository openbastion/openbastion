# NexusRDP — Interactive UI Concept Prototype

A modern Remote Desktop Protocol (RDP) client interface built with **React**, **Tailwind CSS**, and **Lucide Icons**.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the local development server:
   ```bash
   npm run dev
   ```

3. Open the URL printed in your terminal (typically `http://localhost:5173`).
